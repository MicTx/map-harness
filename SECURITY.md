# Security Policy

English | [中文](SECURITY.zh.md)

## Read the safety notice first

Map Harness is experimental developer-preview software. It can execute model-generated code and commands, load third-party plugins, and access files, processes, and the network; it has not undergone a security audit and must not be treated as secure or production-ready. Read [SAFETY.md](SAFETY.md) before running it.

## Supported versions

Only the latest commit of `main` receives security fixes; developer-preview releases carry no backport promise (see the compatibility-breaking warning in [README.md](README.md)).

## Reporting a vulnerability

Report vulnerabilities privately — do not open a public issue. Contact the maintainer through the repository's private vulnerability reporting channel (GitHub Security Advisories once the repository is public) or the maintainer's private contact; include reproduction steps and affected commit ids. Reports receive a best-effort response; there is no SLA and no bounty program.
