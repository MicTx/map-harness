# 地图 LBS 坐标与授权

[English](guide.md) | 中文

## 变更

百度提供者将输入坐标解释为 WGS84，请求 GCJ-02 输出，并使用与高德提供者相同的近似反算转换返回坐标。其网络引用以 `@2` 结尾；`@1` 结果使用厂商默认 BD-09 约定，未执行转换。高德网络引用同样以 `@2` 结尾，因为共享的经度近似变换补齐了遗漏的谐波项。已有运行和报告不会被重写。反算具有米级残余误差，不是测绘级转换。

百度 Place v2 的 total 可能封顶为 150。采集达到该界限时返回 `partial`，不再声称已取回所有匹配 POI；bounds 检索需要厂商高级权限。

天地图默认使用 HTTPS。HTTP 401/403 与百度应用禁用状态 240 返回 `PERMISSION_DENIED`，不再归为暂时不可用。HTTP 429 返回 `RATE_LIMITED`。

## 迁移

1. 为百度分析提供 WGS84 坐标。不要把已有 BD-09 数值直接改标为 WGS84。重新计算受影响的高德/百度覆盖或路线，不要将旧 `@1` 网络身份与 `@2` 混作同一方法比较；把达到截断上限的 POI 集合视为不完整。
2. 允许访问天地图官方 API 的 HTTPS 地址。只有部署确实需要网关时才保留显式 `tianditu.baseUrl`；不要为了兼容网关关闭 TLS 证书验证。
3. 重试 `PERMISSION_DENIED` 前，先在厂商控制台核对 Key 的服务类型与已开通 API。浏览器 SDK Key 不代表具有 Web 服务权限。
4. 运行[提供者验证命令](../../../../map/docs/spatial-accessibility.md)。确认厂商成功响应、坐标单位及新的百度网络引用；测试跳过或 HTTP 200 内携带授权错误，都不是连接成功。
