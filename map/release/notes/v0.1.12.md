## What's new

**Changed**
- **License**: Map Harness's own code now ships under PolyForm Noncommercial 1.0.0 — noncommercial use stays free, commercial use needs written authorization; the vendored upstream code keeps its MIT License.
- **Release integrity**: public archives are staged from an explicit allowlist — private data and credentials are rejected at any depth, and the public branch only changes under an exact remote-state lease.

**Fixed**
- **Layer styling after rename**: renaming a layer keeps its classified (thematic) styling instead of resetting it.
- **Map interaction consistency**: map and client actions stay consistent across retries, selection, and keyboard input.
