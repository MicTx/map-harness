## What's new

**New**
- **Visual map observation**: ask the agent to inspect the current map and cite captured imagery with its camera, source, and map revision.
- **Controlled basemaps**: choose a basemap and label overlay independently while preserving your camera, business layers, and credentials.
- **User annotations**: draw points, lines, polygons, and rectangles, then rename, restyle, edit, delete, or undo them from the map panel.
- **Durable annotation work**: annotations survive refreshes and service restarts, remain private to the session, and export as WGS84 GeoJSON.
- **Protected user edits**: model and collaboration tools cannot overwrite confirmed user annotations.
- **Accessible map panel**: annotation controls work with keyboard input, touch, and narrow dark-mode layouts.
- **Visualization recommendations**: match an analysis goal to a suitable map method and see missing fields or time windows before running it.
