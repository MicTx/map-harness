## What's new

**New**
- **Windows x64 service**: run the script-launched Web service natively on Windows x64 with the same first-run setup and release integrity checks as the macOS build.
- **Clean Windows shutdown**: stop the service with Ctrl-C and receive exit code 130 without leaving background processes behind.

**Fixed**
- **Restored camera scale**: reopening a saved map keeps the zoom level and scale bar in sync with the restored camera.
